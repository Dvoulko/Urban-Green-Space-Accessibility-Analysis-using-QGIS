# Urban Green Space Accessibility Analysis using QGIS
### Evaluating Public Transit, Metro, and Free Parking Networks in Thessaloniki's City Center

---

## 🇬🇧 English Version

### Description
This project focuses on the spatial analysis and mapping of public green spaces, parking infrastructures, and public transit networks (including Metro and buses) within the city center of Thessaloniki, Greece, using **QGIS**. The study aligns with **Sustainable Urban Mobility Plans (SUMP)** and aims to address the challenges of the **Urban Heat Island (UHI)** effect by evaluating multimodal accessibility to urban green infrastructure.

### Software & Tools
*   **GIS Software:** QGIS
*   **Methodology:** Network Analysis / Spatial Accessibility Buffers
*   **Focus Areas:** Sustainable Urban Mobility, Urban Resilience, Green Infrastructure

Χωρική ανάλυση και αποτύπωση ελεύθερων χώρων πρασίνου, υποδομών στάθμευσης και δικτύων ΜΜΜ (συμπεριλαμβανομένου του Μετρό) στο κέντρο της Θεσσαλονίκης με τη χρήση **QGIS**. Η μελέτη εστιάζει στη **Βιώσιμη Αστική Κινητικότητα (ΣΒΑΚ)** και την αντιμετώπιση της **Αστικής Νησίδας Θερμότητας**, αξιολογώντας την πολυτροπική πρόσβαση των πολιτών σε αστικούς πνεύμονες πρασίνου.
